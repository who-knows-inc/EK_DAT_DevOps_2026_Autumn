# Dockerize Now!

Dockerize backend / frontend.

**Type**: Group work

---

## Commence Dockerization

Dockerize the server of your choosing. Next week you will build upon this task with `Docker compose`.

Depending on if the frontend is served by the backend you might end up with 1 or 2 separate containers for the application.

---

## Keep it secret

The goal after next week is to publish the images to a public registry. Because it has to be public, it disallows you to include the SQLite database and secret environment variables in the image.

You must figure out CI/CD/CD without leaking secrets to the public.

There are many ways to approach this interesting problem. Discuss it well with your group and consider the pros and cons of each approach.
